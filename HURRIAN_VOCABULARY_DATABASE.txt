SECTION 22: PHONOLOGICAL NOTES FOR LINEAR A MAPPING
##############################################################################

Key points for mapping Linear A syllabary to Hurrian:

1. Hurrian had NO voiced-voiceless distinction in stops
   - Linear A p/b, t/d, k/g distinctions may be irrelevant
   - Cuneiform shows voiced allophones between voiced phonemes

2. All consonants except /w/ and /j/ could be long or short
   - Gemination was phonemic: kāzi vs. kassi

3. Hurrian vowels: a, e, i, o, u (5 vowels)
   - Generally matches Linear A/B vowel system

4. Hurrian had ḫ (voiceless velar/pharyngeal fricative)
   - Fournet: Linear B q-series should read as Linear A ḫ-series
   - Linear B qa = Linear A ḫa, etc.

5. Hurrian had š (voiceless postalveolar fricative)
   - Linear A s-series may represent both s and š

6. Agglutinative structure means long words:
   - Root + derivation + case + possessive + enclitic chains
   - Multiple signs needed per word in Linear A

7. Word-final vowels common in Hurrian:
   - Most nouns end in -i (e.g., ewri, šarri, eni, purli)
   - Some in -a (kinship: attai, šēna)
   - Matches well with CV syllabary of Linear A
